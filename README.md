# C-Turkey Calibration Tool
This tool provides a user-friendly interface for radiocarbon calibration using the `rcarbon` engine. You can download publication-ready figures. *(Note: Initial loading may take a while as the R runtime environment initializes in your browser).*

## How to Cite
> Altınışık, N.E. (2026) “C-Turkey: A Comprehensive Radiocarbon Dataset from Türkiye,” Journal of Open Archaeology Data, 14. doi:[10.5334/joad.213](https://doi.org/10.5334/joad.213)
